# Retrieve a network or gene-set resource through decoupleR

Retrieve a network or gene-set resource through decoupleR

## Usage

``` r
activity_resource(name, organism = "human", ...)
```

## Arguments

- name:

  Resource name accepted by `decoupleR::get_resource()`.

- organism:

  Organism name accepted by `decoupleR::get_resource()`.

- ...:

  Additional arguments passed to `decoupleR::get_resource()`.

## Value

The native resource table returned by decoupleR.
