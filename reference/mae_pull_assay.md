# Extract an assay matrix

Extract an assay matrix

## Usage

``` r
mae_pull_assay(x, experiment, assay = 1L)
```

## Arguments

- x:

  A `MultiAssayExperiment` object.

- experiment:

  Optional experiment name.

- assay:

  Assay name or one-based assay index.

## Value

A matrix-like assay object.
