# Extract sample classes from a consensus-clustering solution

Extract sample classes from a consensus-clustering solution

## Usage

``` r
cluster_consensus_classes(results, k)
```

## Arguments

- results:

  Result list returned by
  [`cluster_consensus()`](https://younthing.github.io/bulkMAE/reference/cluster_consensus.md).

- k:

  Number of clusters to extract.

## Value

A named integer vector of sample classes.
