# Extract named WGCNA module labels

Extract named WGCNA module labels

## Usage

``` r
coexpr_modules(fit)
```

## Arguments

- fit:

  A native result returned by
  [`coexpr_wgcna()`](https://younthing.github.io/bulkMAE/reference/coexpr_wgcna.md).

## Value

A feature-named vector accepted by
[`coexpr_preservation()`](https://younthing.github.io/bulkMAE/reference/coexpr_preservation.md).
