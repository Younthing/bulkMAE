# P1.3 LINCS reverse-signature drug hypothesis

This mainline answers one question: given a signed query signature, which
compounds in a LINCS/CMap-style reference have connectivity scores that
reverse or mimic it. It uses the existing `drug_*()` entry points. It does
not add docking, molecular dynamics, oncoPredict, or other sensitivity
backends.

## Mainline

- **Question**: After a query up/down set is fixed, which reference
  signatures are connected, and in which direction?
- **Analysis**: `drug_query()` builds the disjoint up/down sets.
  `drug_lincs()` searches a reference through `signatureSearch::gess_lincs()`
  and still returns the native `gessResult`. `drug_lincs_table()` extracts
  the ranked compound table without recomputing WTCS, NCS, or Tau.
- **Required figures**: ranked connectivity lollipop, compound × cell
  heatmap, score waterfall. The package also has an overlap bar of
  `N_upset` / `N_downset`. The vignette shows the first three.
- **Out of scope**: docking/MD, silent ExperimentHub downloads of the full
  LINCS L1000 or CMap libraries, new drug-sensitivity methods, enrichment
  wrappers, and wet-lab or clinical-use claims.

## Offline and synthetic constraints

Full prebuilt identifiers (`lincs`, `lincs2`, `cmap`, ...) are ExperimentHub
resources. Ordinary vignette and CI runs must not download them.

When no local HDF5 path is available:

1. Build a signed query with `drug_query()` from named statistics. Those
   statistics may come from a real DE table or from a labelled diagnostic
   vector.
2. Use `drug_lincs_example()` as a **diagnostic toy table**. It has the
   same columns as `gess_lincs()` (`pert`, `cell`, `WTCS`, `NCS`, `Tau`,
   `N_upset`, `N_downset`, ...) but the scores are synthetic.
3. Rank and plot through `drug_lincs_table()` and the `plot_lincs_*()`
   helpers.

The production call remains:

```r
hits <- drug_lincs(query, reference_database = local_h5_or_cached_id)
drug_lincs_table(hits)
```

`signatureSearch` ships a small `inst/extdata/sample_db.h5`. Tests that
need a live search look for `BULKMAE_LINCS_DB` or skip. They never fetch a
gated commercial database.

## Honesty

- Axis labels name the score that is actually present (`NCS`, `Tau`,
  `WTCS`, or `NCSct`). They do not say "efficacy" or "validation".
- `Reverse` / `Mimic` is the sign of the connectivity statistic.
- Tau is only meaningful on a complete LINCS reference. The toy table
  includes a Tau column so the axis-labelling contract can be tested; the
  vignette treats it as diagnostic.
- Captions, alt text, and this note must keep the words hypothesis and
  diagnostic whenever the table is synthetic.

## Interface boundary

- `drug_lincs()` does not change its native return type.
- Plot constructors consume already-computed tables and return one
  unprinted ggplot with `theme_bulkmae()` and `plot_save()` dimensions.
- No binary figures are committed. Preview PNGs belong under ignored
  `docs/plot-previews/` or `/opt/cursor/artifacts/`.
