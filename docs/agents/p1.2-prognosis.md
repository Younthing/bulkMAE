# P1.2 预后建模路线

这一主线只回答一件事：在 MultiAssayExperiment
上，如何用既有 `surv_*()` / `score_signature()` 接口画出文献里的预后图，并且在没有真实随访时把结局标成合成诊断数据。

## 主线

- **问题**：官方 `airway` 演示没有随访。如何对齐样本、拟合 Kaplan–Meier / Cox、分层风险分数，而不把同一队列上的图说成独立外部验证？
- **分析**：预先指定的 signature 打分、风险组切割、Kaplan–Meier、单变量/多变量 Cox。
- **标准图**：KM（含 number-at-risk）、Cox 森林图（HR + CI）、风险分数分布或按结局分组的箱线图。时间依赖 ROC / C-index 图不另加依赖；C-index 只在正文用 `survival::concordance()` 报告。
- **不在范围**：LINCS、对接/MD、富集封装、把合成随访写成真实临床队列。

## 合成结局

`airway` 的 `colData` 没有 time/event。教程用两种诚实写法：

1. 把**合成**随访列按样本名挂到 airway MAE 上，只演示对齐，不把 n = 8 说成预后研究。
2. 用 `mae_simulate()` 的合成表达和合成 `survival_time` / `event` 画可读的诊断图。

图注、alt text 和正文都必须写明结局是 synthetic / diagnostic。包内 `mae_simulate()` 的注释和结局本来就没有生物学含义。

## 接口边界

- 分析函数继续返回原生 `survfit` / `coxph`，或从已拟合对象抽出普通 data frame。
- `surv_cox_table()`、`surv_cox_univariable()`、`surv_risk_groups()` 不重写 survival 后端。
- `plot_surv_km()`、`plot_surv_forest()`、`plot_surv_risk()` 只画已经算好的结果，返回未打印的单个 ggplot，主题为 `theme_bulkmae()`。
- 不引入 survminer。KM 的 at-risk 表画在同一 ggplot 里。
