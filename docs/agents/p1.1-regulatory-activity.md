# P1.1 调控活性（regulatory activity）

## What landed

- Reused the existing decoupleR adapters: `activity_decouple()`,
  `activity_tf()`, `activity_progeny()`, `activity_matrix()`.
- Added one thin post-process helper, `activity_contrast()`, which compares
  already-inferred per-sample activity scores between two groups. It does not
  run a new backend and it is not enrichment.
- Added the literature activity figure set:
  `plot_activity_heatmap()`, `plot_activity_rank()`, `plot_activity_sample()`,
  `plot_activity_volcano()`.
- Added `vignettes/regulatory-activity.Rmd`: real `airway` VST expression plus
  a **diagnostic synthetic** signed network so the vignette stays offline.
  Captions state n = 8 and that the regulons are not CollecTRI/DoRothEA/PROGENy.

## Out of scope (this route)

- Enrichment wrappers or GO/KEGG barplots
- Survival / prognosis
- LINCS drug hypotheses
- MEGENA / CEMiTool / extra DoRothEA shells
- PPI, docking, or MD

`activity_decouple()` can still run enrichment-style decoupleR statistics
(`ora`, `fgsea`, `gsva`, `aucell`). Activity plots warn if those scores are
passed in; they do not relabel enrichment as activity.
