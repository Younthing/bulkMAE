# Official implementation sources

Audit date: 2026-08-23.

This document maps each adapter family to the official package documentation or
maintainer tutorial used to design it. The wrappers intentionally expose only a
small, stable subset of each backend. Consult the linked source before changing
defaults or adding parameters.

## Method boundaries and deliberate exclusions

- KEGG/Reactome wrappers do not guess identifier types or organism mappings.
  Record the database and annotation release used for every result.
- CIBERSORTx execution is not automated because it is external and may involve
  protected data upload.
- PPI and regulatory-network wrappers do not claim causal direction.
- `coexpr_differential()` implements DCA as differential
  co-expression. It is not discriminant correspondence analysis or decision
  curve analysis; those require different data contracts.
- Module preservation requires explicit reference/test MAEs and a named
  reference module vector; the wrapper does not infer cohort roles or modules.
- External validation is a study split and transportability problem, not a
  single model-fitting function. The scoring and model wrappers provide the
  primitives without hiding cohort boundaries.
